# Experiments

The curated reproducibility run is generated by:

```bash
./scripts/run-verified-small.sh
```

Tracked outputs:

- `results/verified-small.csv` — per-trial timing/recovery rows;
- `results/verified-small-coverage.csv` — exact unique-state table coverage;
- `results/verified-small-environment.txt` — machine, OS, Java, and Maven
  metadata.

`docs/VERIFIED_RESULTS.md` is generated from the two CSV files.

The runner accepts explicit CLI parameters; see `ExperimentRunner.Config` for
the supported flags. Always keep the seed and full parameter set when
publishing a result.
